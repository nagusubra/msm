## What this repo is

**TILL** — a cash-timing solver for shift workers, built for the ZayZoon hackathon. Not a budgeting dashboard.

> Every tool in this category answers one question: how much can I take today. None answer the one that matters: what is the cheapest way through the next two weeks. TILL projects a worker's cash position forward to the next cliff, prices every route across the gap, and ranks working above borrowing because in this dataset working is almost always cheaper.

The loop, and the entire scope: **cliff detected → gap priced → route chosen.** Three screens, one loop, finished. Anything outside that loop is out of scope (see `docs/spec.md` §7 cut list).

## Load-bearing rules

1. **Zero money literals in JSX.** Engine / seed via props only. Grep `\$\d` in `src/app` and `src/components` must be empty except comments.
2. **Ledger is derived, never read.** Balance columns reconcile ~2.2% / 20.5%; 34.1% of credits are followed by a balance decrease.
3. **Time is data.** `meta.today` = `2026-05-27T18:40`. No `Date.now()` / `new Date()` feeding rendered numbers.
4. **Money is `type Money = number`, CAD to 2dp** — `round2()`, cent epsilon, `formatMoney` only.
5. **`src/lib` is pure.** No React, fetch, fs, randomness.
6. **No `any` at a module boundary.**
7. **Amber vs haze is semantic.** Rust = cliff days and shortfalls ONLY.
8. **Every number reconciles.** Change `docs/numbers.md` first, then grep survivors.
9. **No invented data.** Seed / cohort rows are the dataset.
10. **No TODO / placeholder** in shipped code.

## Hard constraints (spec §14)

Two routes only: `/` and `/math`. No DB, auth, API keys, runtime network, `localStorage` / `sessionStorage`, or `<form>`. CSV parsing in `scripts/` only. Mobile-first 390px phone shell.

## Exact formulas (gotchas)

See `docs/spec.md` §16 and `docs/numbers.md`. Common mistakes:

- Earnings land on work date when `paid_same_day`, else **work date + 5 days**.
- `is_cliff` = `outflow >= 0.25 × monthlyObligationTotal`.
- `netHourly` = Σ net ÷ Σ hours over shifts.
- `solveGap`: amount **and** time **and** `!conflicts`; late rows return `too_late`, never dropped.
- Advance: `min(gap, 200, 0.5 × periodNet, 1000)`, floor $20, dataset median fee.
- `safeToSpendToday` returns `max(0, …)`.
